# Spec Summary (Lite)

Completar a Explainability API do Neural-Hive-Mind integrando consenso hierárquico (GAPS-03) e métodos de atribuição de features (SHAP) para fornecer transparência completa nas decisões multi-agente.

A API existente (65%) possui endpoints de consulta e ledger básico. Esta spec adiciona: (1) campos de senioridade e pesos hierárquicos nas explicações, (2) SHAP calculator para atribuição de features, (3) extração estruturada de reasoning factors, (4) métricas de qualidade de explicação, e (5) suporte a múltiplos formatos de saída.
