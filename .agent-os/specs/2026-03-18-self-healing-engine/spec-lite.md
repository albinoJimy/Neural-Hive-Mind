# Spec Summary (Lite)

Sistema de auto-recuperação do Neural Hive-Mind com detecção automática de incidentes via health checks, remediação via playbooks YAML configuráveis, validação de ações críticas via OPA, deploy em Kubernetes com Helm chart e testes E2E completos. Objetivo: reduzir MTTR e intervenção manual através de recuperação automatizada de falhas comuns (crash, timeout, Kafka lag, deadlock, memory leak).
