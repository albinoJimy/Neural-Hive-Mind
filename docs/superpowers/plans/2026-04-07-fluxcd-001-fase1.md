> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement FluxCD GitOps foundation for Neural-Hive-Mind - staging cluster, 8 core services with HelmReleases, ImageUpdateAutomation, and promotion pipeline

# FluxCD GitOps Toolkit - Staging Cluster
apiVersion: v1
kind: Namespace
metadata:
  name: flux-system
  labels:
    pod-security.kubernetes.io/enforce: restricted

---
apiVersion: source.toolkit.fluxcd.io/v1
kind: GitRepository
metadata:
  name: neural-hive-mind
  namespace: flux-system
spec:
  interval: 1m
  url: ssh://git@github.com/albinoJimy/Neural-Hive-Mind.git
  ref:
    branch: main
  secretRef:
    name: neural-hive-mind-git-ssh
  ignore: |
    /*
    !/infrastructure/fluxcd
    !/helm-charts

---
apiVersion: kustomize.toolkit.fluxcd.io/v1
kind: Kustomization
metadata:
  name: infrastructure
  namespace: flux-system
spec:
  interval: 5m
  path: ./infrastructure/fluxcd/clusters/staging/infrastructure
  prune: true

---
apiVersion: kustomize.toolkit.fluxcd.io/v1
kind: Kustomization
metadata:
  name: core-services
  namespace: flux-system
spec:
  interval: 2m
  path: ./infrastructure/fluxcd/clusters/staging/services
  prune: true
  dependsOn:
    - name: infrastructure
```

Write: `infrastructure/fluxcd/clusters/dev/flux-system/image-automation.yaml`

```yaml
# ImageUpdateAutomation - Dev Cluster
# Atualiza automaticamente as tags de imagem no Git quando novas versões são publicadas

apiVersion: image.toolkit.fluxcd.io/v1
kind: ImageUpdateAutomation
metadata:
  name: dev-images
  namespace: flux-system
spec:
  interval: 1m
  sourceRef:
    kind: GitRepository
    name: neural-hive-mind
  gitCommitMessage:
    prefix: "[flux-dev] "
  update:
    strategy: Setters
    paths:
      - ./infrastructure/fluxcd/clusters/dev
  checkout:
    gitRepository:
      name: neural-hive-mind
      namespace: flux-system
  commit:
    authorEmail: flux-dev@neural-hive-mind.local
    authorName: Flux Dev Automation
  push:
    branch: develop
```

# Neural-Hive-Mind GitOps with FluxCD

## Overview

This directory contains FluxCD GitOps manifests for deploying Neural-Hive-Mind services across multiple environments.

## Architecture

```
infrastructure/fluxcd/
├── clusters/
│   ├── dev/         # Development (branch: develop)
│   ├── staging/     # Staging (branch: main)
│   └── prod/        # Production (branch: main + tags)
```

## Environments

| Environment | Branch | Sync Interval | Image Policy |
|-------------|--------|---------------|--------------|
| Dev         | develop | 30s | latest tag |
| Staging     | main    | 2m  | semver >=1.0.0 |
| Prod        | main    | 5m  | exact tag |

## Services

The following services are managed by FluxCD:

1. gateway-intencoes
2. semantic-translation-engine
3. consensus-engine
4. orchestrator-dynamic
5. approval-service
6. worker-agents
7. queen-agent
8. service-registry

## Workflow

### Dev Deployment (Automatic)

1. Push to `develop` branch
2. GitHub Actions builds and pushes image with `:dev` tag
3. FluxCD detects new image and updates cluster automatically

### Staging Promotion (Automatic)

1. Merge `develop` → `main`
2. GitHub Actions builds and pushes image with semver tag
3. FluxCD updates staging cluster automatically

### Production Deployment (Manual)

1. Create git tag: `git tag -a v1.2.3 -m "Release v1.2.3"`
2. Push tag: `git push origin v1.2.3`
3. Update production manifests with exact tag
4. FluxCD deploys to production

## Commands

### Check FluxCD status

```bash
flux get sources all
flux get kustomizations all
```

### Reconcile manually

```bash
flux reconcile source git neural-hive-mind --namespace flux-system
flux reconcile kustomization core-services --namespace flux-system
```

### View logs

```bash
flux logs --all-namespaces --kind=Kustomization
```

## Troubleshooting

### Images not updating

Check ImageRepository and ImagePolicy:
```bash
flux get image repository all
flux get image policy all
```

### Drift detection

```bash
flux reconcile kustomization --with-source
```

## References

- [FluxCD Documentation](https://fluxcd.io/docs/)
- [HelmRelease Guide](https://fluxcd.io/docs/guides/helmreleases/)
