# Design: GAP-01 + GAP-02 — Kafka Flow Fixes

**Data:** 2026-04-07
**Status:** Design Aprovado
**Estimativa Total:** 4 dias (1 dia GAP-01 + 3 dias GAP-02)

---

## Overview

Corrigir dois gaps críticos que quebram o fluxo principal do Neural-Hive-Mind:
- **GAP-01:** Semantic Translation Engine produz em tópico errado
- **GAP-02:** Execution results não têm consumer — feedback loop incompleto

---

## Problema Atual

```
┌─────────────┐  cognitive-plans   ┌──────────────┐
│     STE     │ ──────────────────> │   (Ninguém)  │ ❌ DEAD END
└─────────────┘                     └──────────────┘

┌─────────────┐   plans.ready      ┌──────────────┐
│   (Vazio)   │ <────────────────── │  Consensus   │ Waiting...
└─────────────┘                     └──────────────┘

┌─────────────┐ execution.results  ┌──────────────┐
│   Workers   │ ──────────────────> │   (Vazio)    │ ❌ DEAD END
└─────────────┘                     └──────────────┘
```

**Impacto:**
- Fluxo STE → Consensus não funciona
- Workflows Temporal ficam esperando timeout
- Telemetria incompleta
- Consolidação de resultados quebrada

## Solução Proposta

### GAP-01: Topic Alignment (1 dia)

**Mudança:** Alterar STE para produzir em `plans.ready` em vez de `cognitive-plans`

**Justificativa:**
- Helm charts já usam `plans.ready`
- Schema Registry configurado para `plans.ready-value`
- Consensus Engine já está configurado corretamente
- Minimiza impacto — apenas 1 linha de código

**Arquivos:**
| Arquivo | Mudança |
|---------|---------|
| `services/semantic-translation-engine/src/config/settings.py:51` | `kafka_plans_topic: 'plans.ready'` |

## Componentes Detalhados

### ExecutionResultConsumer

```python
class ExecutionResultConsumer:
    """Consumer Kafka para execution.results"""

    TOPIC = "execution.results"

    def __init__(
        self,
        config,
        temporal_client: Client,
        redis_client,
        metrics
    ):
        self.config = config
        self.temporal_client = temporal_client
        self.redis_client = redis_client
        self.metrics = metrics
        self.consumer = None

    async def initialize(self):
        """Inicializar consumer Kafka"""
        self.consumer = AIOKafkaConsumer(
            self.TOPIC,
            bootstrap_servers=self.config.kafka_bootstrap_servers,
            group_id=self.config.execution_result_consumer_group,
            auto_offset_reset="latest",
            enable_auto_commit=False
        )
        await self.consumer.start()

    async def start(self):
        """Loop de consumo"""
        async for message in self.consumer:
            await self._process_result(message)

    async def _process_result(self, message):
        """Processa ExecutionResult e envia signal para Temporal"""
        # 1. Deserializar
        result_data = self._deserialize(message)

        # 2. Recuperar workflow_id do cache
        workflow_id = await self._get_workflow_for_ticket(
            result_data['ticket_id']
        )

        if not workflow_id:
            logger.warning('workflow_id_not_found')
            await self.consumer.commit()
            return

        # 3. Enviar signal
        await self._send_workflow_signal(
            workflow_id=workflow_id,
            ticket_id=result_data['ticket_id'],
            result=result_data
        )

        # 4. Commit
        await self.consumer.commit()
```

### Cache de workflow_id

**Quando:** Ao criar ticket no Orchestrator
**Onde:** `ticket_generation.py`

```python
async def cache_workflow_mapping(
    ticket_id: str,
    workflow_id: str,
    redis_client
):
    """Cache mapeamento ticket_id → workflow_id"""
    cache_key = f"workflow:by:ticket:{ticket_id}"
    await redis_client.setex(cache_key, 86400, workflow_id)  # 24h
```
