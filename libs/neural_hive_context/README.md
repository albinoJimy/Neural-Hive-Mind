# Neural Hive Context

Context Layer library for Neural Hive Mind.

## Installation

```bash
pip install neural-hive-context
```

## Usage

```python
from neural_hive_context import RichContext, WorkflowType, IWorkflowClassifier
```

## Components

- **RichContext**: Aggregated context model
- **WorkflowClassifier**: Classify ORCHESTRATION vs GENERATION workflows
- **PIIDetector**: Detect personally identifiable information
